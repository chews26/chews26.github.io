# 이빛나 포트폴리오

교육 운영과 소프트웨어 개발 경험을 담은 정적 포트폴리오 웹사이트입니다.

https://chews26.github.io

## 구성

- `index.html`: 진입 페이지
- `content.js`: 프로젝트 내용과 성과 지표
- `app.js`: 프로젝트 탐색과 상세 화면
- `styles.css`, `editorial.css`: Pretendard 기반 반응형 디자인
- `assets`: 이미지, 폰트, 아이콘 및 라이선스

별도 빌드 없이 GitHub Pages의 main 브랜치 루트에서 배포됩니다.

Pretendard는 SIL OFL, Lucide는 동봉한 라이선스를 따릅니다.
소개, 프로젝트 목록, 경력과 역량, 연락처를 독립된 섹션으로 구성했습니다.
프로젝트 목록은 왼쪽 작업 자료와 오른쪽 핵심 액션을 함께 보여줍니다.
생성 사진은 화면에서 제외했고 실제 Tripf 화면, NPS 자료, 성과 수치와 업무 흐름을 사용합니다.
